# CSCI 2020U Project Charter & Work Contract
## 1. Project Overview
* **Project members:** Noah Hewitt, Dylan Reid, Ngoc Kieu Minh Do
* **Product Name:** Web based War but better
* **Project Description:** Video Game, a Godot-based card game war with added effects to each card and a hand of 4-6 cards, where two players can connect to a central server via Sockets. Players have Online or against CPU. At the start of the game, each player draws a set amount of cards. They may view the set at any point in the game, but its value is hidden from the other players until they place the card. After drawing cards players enter a game loop of placing down one card without revealing. 

* **Tech Stack:** Godot, GDscript, Enet
